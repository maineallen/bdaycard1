# bdaycard1
                                    [Build one self-contained HTML file for an interactive birthday card. Everything (HTML, CSS, JS, images as base64) goes in that one file so it works as a single shareable link. Vanilla HTML/ CSS/JS, no frameworks. I'm attaching 4 images: a cover photo, a letter with my message, an envelope, and a cake with lit candles. Scrapbook/ collage aesthetic, warm kraft-paper background. Structure: The card starts closed, showing only the cover, centered on screen with space above it (not touching the top).Tapping the cover opens it on a center hinge into a two-page spread: the letter page on the left, the candles page on the right. The whole spread stays centered when open.A "back to cover" button closes the spread and returns to the centered cover.Letter page (left):Show the envelope with the letter tucked inside, peeking out.Tapping the letter lifts it forward so I can read it. It should come to the front but not fill the whole page, keep margins around it. Tapping again tucks itback into the envelope.Candles page (right):Cut the flames out of the cake image into separate transparent PNGs, and erase the flames from the cake itself, so the flames are their own elements that keep the painted collage look.I blow into my mic to blow out the candles. Use the Web Audio API to detect blowing. The real cut-out flames bend sideways with the blow, and after about 0.5 seconds of blowing they go out. Show a small level meter so I can see the mic is picking me up. After they're out, show a "make a wish, [name]" message with confetti, and a relight button to try again.Add a hold-to-blow fallback (button or spacebar) for when the mic is blocked.Important:The mic only works over https, so build in the fallback and note that I need to host the file (not open it locally) for blowing to work.Test each interaction and fix issues before finishing.Iterate with me one change at a time after the first version.]
